# Context folder — functional-leader

Every convening on this bench reads this folder first, at every depth, and cites it as T1 ("context: <file>, <section>"). Put here what is stable across efforts: the things the council should already know before it starts. Effort-specific material goes in the effort's `documents/`.

Suggested files for this bench: function.md (the function's remit, budget and headcount), organization.md (the company in a page and where the function sits), rules.md (the policies and regulations the function lives under), glossary.md, decisions.md.

Keep each file short and dated at the top. When something here changes materially, note it in `decisions.md` or at the top of the file so later rounds can see what moved.
